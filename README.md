# プロコン2026 講習資料

プロコン2026に向けた講習会の資料とサンプルコードのリポジトリです。

## ディレクトリ構成

### 📂 [curriculum](./curriculum)
講習の進め方や解説がまとまっています。Stepごとに段階を踏んで学習できるようになっています。
- **Step1**: 開発環境の準備とHTML/CSS/JSの基礎
- **Step2**: クリッカーゲーム制作を通じた実践
- **Step3**: さらなる機能追加・応用
- **Step4**: 発展課題

### 📂 [clicker](./clicker)
講習で作成する「クリッカーゲーム」のサンプルプロジェクトです。
- `index.html`: ゲームの画面構造
- `style.css`: ゲームの見た目
- `script.js`: ゲームのロジック（点数計算など）

## 始め方
`curriculum` フォルダ内の各Stepの資料を順番に読み進めてください。
まずは [curriculum/Step1](./curriculum/Step1) から始めましょう。
