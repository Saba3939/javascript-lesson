# Step 2 Lv.5: 繰り返し（Loop）

## 目標
たくさんのデータを一気に処理できるようになろう！

## 1. 繰り返し（Loop）ってなに？
「100回ジャンプする」「リストにある全員に挨拶する」など、同じような処理を何度も繰り返すことです。
プログラミングでは、人間がやると面倒な繰り返し作業を一瞬で終わらせることができます。

## 2. 配列と繰り返しの最強コンボ
Lv.6で習った「配列」の中身を、順番に全部処理したい時によく使います。

### forEach（フォー・イーチ）
配列専用の便利な繰り返しコマンドです。
「配列の要素ひとつひとつに対して、この処理をしてね」と命令できます。

```javascript
const foods = ["ラーメン", "カレー", "寿司"];

// foodsの中身を順番に food という名前で取り出して...
foods.forEach(function(food) {
    console.log(food + "はおいしい！");
});
```

**実行結果:**
```
ラーメンはおいしい！
カレーはおいしい！
寿司はおいしい！
```

### （参考）for文
回数を指定して繰り返したい時は `for` 文を使いますが、少し書き方が難しいです。
まずは `forEach` をマスターしましょう！

```javascript
// 0から2まで、1ずつ増やしながら繰り返す
for (let i = 0; i < 3; i++) {
    console.log(i + "回目の実行");
}
```

## やってみよう！
次の条件を満たすプログラムを書いてみましょう。

1. `items` という配列を作る（Lv.6と同じでOK）。
2. `forEach` を使って、全てのアイテムの **名前と値段** を表示する。
   例：「木の剣は100円です」

### 解答例
```javascript
const items = [
    { name: "木の剣", price: 100 },
    { name: "鉄の剣", price: 500 },
    { name: "勇者の剣", price: 1000 }
];

items.forEach(function(item) {
    console.log(item.name + "は" + item.price + "円です");
});
```
