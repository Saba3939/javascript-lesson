# Step 2 Lv.5
## 繰り返し（Loop）

---

## 目標

**たくさんのデータを一気に処理できるようになろう！**

---

## 1. 繰り返し（Loop）ってなに？

「100回ジャンプする」「リストにある全員に挨拶する」など、同じような処理を何度も繰り返すことです。
プログラミングでは、人間がやると面倒な繰り返し作業を一瞬で終わらせることができます。

---

## 2. 配列と繰り返しの最強コンボ

Lv.4で習った「配列」の中身を、順番に全部処理したい時によく使います。

---

### for...of 文

配列の中身をひとつずつ取り出して処理する、とても便利な書き方です。
「配列の要素ひとつひとつに対して、この処理をしてね」と命令できます。

```javascript
const foods = ["ラーメン", "カレー", "寿司"];

// foodsの中身を順番に food という名前で取り出して...
for (const food of foods) {
    console.log(food + "はおいしい！");
}
```

**実行結果:**
```
ラーメンはおいしい！
カレーはおいしい！
寿司はおいしい！
```

---

## やってみよう！

次の条件を満たすプログラムを書いてみましょう。

1. `items` という配列を作る（Lv.4と同じでOK）。
2. `for...of` を使って、全てのアイテムの **名前と値段** を表示する。
   例：「木の剣は100円です」

---

### 解答例

```javascript
const items = [
    { name: "木の剣", price: 100 },
    { name: "鉄の剣", price: 500 },
    { name: "勇者の剣", price: 1000 }
];

for (const item of items) {
    console.log(item.name + "は" + item.price + "円です");
}
```
