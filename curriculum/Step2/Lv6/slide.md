# Step 2 Lv.6
## 関数（Function）

---

## 目標

**処理をひとまとめにして、好きな時に発動できるようになろう！**

---

## 1. 関数（Function）ってなに？

関数（かんすう）は、いくつかの命令をまとめて名前をつけた**「魔法の呪文」**のようなものです。
一度呪文を作っておけば、あとで何度でも唱える（実行する）ことができます。

---

### 関数の作り方（定義）

`function`（ファンクション）という言葉を使います。

```javascript
// 「sayHello」という名前の呪文を作る
function sayHello() {
    console.log("こんにちは！");
    console.log("いい天気ですね。");
}
```

> **注意**: これだけでは何も起きません！呪文は「作った」だけでは発動しないからです。

---

### 関数の使い方（呼び出し）

作った関数を使うことを「呼び出し（Call）」と言います。
名前の後ろに `()` をつけると発動します。

```javascript
// 呪文を唱える！
sayHello();
```

---

## 2. スコープ（有効範囲）

関数の中で作った変数は、関数の外では使えません。これを「スコープ」と言います。
逆に、関数の外で作った変数は、関数の中でも使えます。

```javascript
let count = 0; // 外で作った変数はどこでも使える

function countUp() {
    count += 1; // OK！
    let temp = 10; // 関数の中で作った変数
}

// console.log(temp); // エラー！外からは見えない
```

---

## やってみよう！

次の条件を満たすプログラムを書いてみましょう。

1. `score` という変数を作る（初期値0）。
2. `addScore` という名前の関数を作る。
3. 関数の中で、`score` に `10` を足して、`console.log` で表示する。
4. 最後に、`addScore()` を呼び出して実行する。

---

### 解答例

```javascript
let score = 0;

function addScore() {
    score += 10;
    console.log("現在のスコア:", score);
}

// 実行する
addScore();
```
