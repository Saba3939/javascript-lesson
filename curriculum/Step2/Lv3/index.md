# Step 2 Lv.3: 条件分岐

## 目標
ゲームのルール（購入判定など）を作れるようになろう！

## 1. 条件分岐（じょうけんぶんき）ってなに？
「もし〜なら、〇〇する」「そうでなければ、××する」というように、状況によって動きを変えることです。
ゲームでは「お金が足りていたら買える」「HPが0になったらゲームオーバー」などで使います。

### if文（イフぶん）の書き方
`if`（もし）と `else`（エルス：そうでなければ）を使います。

```javascript
let money = 100;
let price = 50;

// もし、所持金が値段以上なら
if (money >= price) {
    console.log("買えます！");
} else {
    // そうでなければ（足りなければ）
    console.log("お金が足りません...");
}
```

## 2. 比較演算子（ひかくえんざんし）
数を比べるための記号です。

- `A >= B`: AはB **以上** （AとBが同じでもOK）
- `A > B`: AはB **より大きい** （同じだとダメ）
- `A <= B`: AはB **以下**
- `A < B`: AはB **より小さい**
- `A === B`: AとBは **等しい** （イコールは3つ書くのが基本！）
- `A !== B`: AとBは **等しくない**

## やってみよう！
次の条件を満たすプログラムを書いてみましょう。

1. `money`（所持金）と `price`（値段）の2つの変数を作る。
2. `if` 文を使って、「所持金が値段以上」かどうかチェックする。
3. 条件を満たした時だけ、`console.log("購入成功！")` と表示する。
4. `money` の値をいろいろ変えて、正しく動くか試してみる。

### 解答例
```javascript
let money = 200;
let price = 150;

if (money >= price) {
    console.log("購入成功！");
    // 買ったのでお金を減らす処理も書けるよ
    money -= price; 
} else {
    console.log("お金が足りないよ");
}
```
