# オブジェクト
## まとまったデータを扱おう

---

## 1. オブジェクト（Object）ってなに？

関連するデータをひとまとめにした「情報のカタマリ」のことです。
「アイテム」には「名前」「値段」「効果」など、いろいろな情報があります。これを1つにまとめます。

### オブジェクトの作り方
波括弧 `{ }` を使って、`キー: 値` のペアで書きます。

```javascript
// 「cursor」というアイテムの情報をまとめる
const cursor = {
    name: "強化カーソル", // 名前
    price: 15,          // 値段
    power: 1            // 効果
};
```

---

<!-- _class: section-header -->

# ドット記法
## データを取り出そう

---

## 2. データの取り出し方（ドット記法）

まとめた情報から、特定のものだけを取り出すには `.`（ドット）を使います。

```javascript
console.log(cursor.name);  // "強化カーソル" と表示される
console.log(cursor.price); // 15 と表示される
```

# 配列
## データを並べよう

---

## 3. 配列（Array）ってなに？

アイテムが100個あったら、変数を作るのが大変です。
そこで登場するのが **配列（リスト）** です。
角括弧 `[ ]` を使って、データを順番に並べて管理します。

```javascript
// 好きな食べ物リスト
const foods = ["ラーメン", "カレー", "寿司"];
// アイテムリスト（オブジェクトを並べることもできる！）
const items = [
    { name: "カーソル", price: 15 },
    { name: "おばあちゃん", price: 100 },
    { name: "工場", price: 500 }
];
```

---

### 配列の中身を取り出す

配列には「0番目、1番目、2番目...」という番号（インデックス）がついています。
**※プログラミングでは「0」から数えます！**

```javascript
console.log(foods[0]); // "ラーメン"
console.log(foods[1]); // "カレー"
console.log(items[1].name); // "おばあちゃん"
```

# やってみよう！
## 実際に手を動かしてみよう 🖊️

---

## やってみよう！

次の条件を満たすプログラムを書いてみましょう。

1. `items` という名前の配列を作る。
2. 配列の中に、好きなアイテム（オブジェクト）を2つ以上入れる。
3. `console.log` を使って、**2番目のアイテムの名前** を表示する。

---

### 解答例

```javascript
const items = [
    { name: "木の剣", price: 100 },
    { name: "鉄の剣", price: 500 }, // これが2番目（インデックス1）
    { name: "勇者の剣", price: 1000 }
];

// 2番目なので [1] を指定する
console.log(items[1].name); // "鉄の剣"
```
