# 定数・変数
## データを箱に入れよう

---

## 1. 定数と変数（データの箱）

プログラムの中で、数字や文字を覚えておくための「箱」には2種類あります。

### const（定数）: 書き換えられない箱
中身を一度決めたら変更できない箱です。
基本的には、**まず `const` を使う** ようにしましょう。（constant = 定数）

```javascript
// 名前は変わらないので const
const myName = "Kento";

// myName = "Taro"; // エラー！書き換え禁止
```

---

### let（変数）: 書き換えられる箱

ゲームのスコアやカウント数など、**後で中身が変わるもの** には `let` を使います。

```javascript
// スコアは変化するので let
let score = 0;

// 後で上書きできる（再代入）
score = 100;
```

# データ型
## データの種類を知ろう

---

## 2. データ型（データの種類）

箱に入れるデータには種類があります。

- **数値 (Number)**: 数字。計算ができる。 `0`, `100`, `-5`
- **文字列 (String)**: 文字。`"`（ダブルクォート）または `'`（シングルクォート）で囲む。 `"Hello"`, `'あいうえお'`

```javascript
const age = 20;       // 数値
const text = "20";    // 文字列（計算できない！）
```

## 計算してみよう

## 3. 演算（計算すること）

### 数値の計算（算術演算子）

| 記号 | 意味 | 例 (`a=10`, `b=2`) |
| :---: | :--- | :--- |
| `+` | 足し算 | `a + b` → `12` |
| `-` | 引き算 | `a - b` → `8` |
| `*` | 掛け算 | `a * b` → `20` |
| `/` | 割り算 | `a / b` → `5` |
| `%` | 余り | `10 % 3` → `1` |

---

### 文字列の結合

`+` を文字に使うと、文字同士をくっつけることができます。

```javascript
const firstName = "Kento";
const greeting = "Hello, " + firstName; // "Hello, Kento" になる
```

---

### 便利な書き方（複合代入演算子）

自分自身に計算して保存し直す書き方です。 `let` で作った変数に使います。

```javascript
let count = 0;

count += 1;  // count = count + 1 と同じ（1増やす）
count -= 5;  // count = count - 5 と同じ（5減らす）
```

# console.log
## 動作を確認しよう

---

## 4. コンソールで確認（console.log）

プログラムの裏側で何が起きているかを確認するために、`console.log` を使います。
ブラウザの「検証ツール（デベロッパーツール）」の「Console」タブに結果が表示されます。

```javascript
let hp = 100;
console.log("現在のHP:", hp); // 現在のHP: 100 と表示される
```

# やってみよう！
## 実際に手を動かしてみよう 🖊️

## やってみよう！

次のプログラムを書いて、コンソールで結果を確認してみましょう。

1. `const` で `price`（値段）という定数を作り、`150` を入れる。
2. `let` で `money`（所持金）という変数を作り、`1000` を入れる。
3. `money` から `price` を引く（買った！）。
4. コンソールに `"残金: " + money` と表示する。

---

### 解答例

```javascript
const price = 150;
let money = 1000;

// 購入処理（引き算）
money -= price; // money = money - price;

// 結果表示
console.log("残金: " + money); 
// -> "残金: 850" と表示されるはず！
```
