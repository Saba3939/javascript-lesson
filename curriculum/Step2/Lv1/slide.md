## 1. Webを構成する3つの要素

Webページは、役割の違う3つの言葉が協力してできています。

1.  **HTML**（エイチティーエムエル）: **構造**を作る（骨組み、内容）
2.  **CSS**（シーエスエス）: **見た目**を整える（色、大きさ、配置）
3.  **JavaScript**（ジャバスクリプト）: **動き**をつける（計算、アニメーション）

このLv.1では、**HTML** と **CSS** を準備します。

---

## 2. HTML: ページの構造

HTMLは、**タグ**を使って文書の構造を作ります。

### タグの基本
基本は「開始タグ」と「終了タグ」で中身を挟みます。
`<要素名>中身</要素名>`

```html
<h1>私のプロフィール</h1>
<p>こんにちは、ケンです。</p>
<button>クリックしてね</button>
```

---

### 空要素（Void Elements）

中身を持たない、終了タグがいらない要素もあります。

- `<img>`: 画像を表示する
- `<input>`: 文字を入力する欄
- `<br>`: 改行する

```html
<!-- 終了タグがいらない -->
<img src="icon.png" alt="アイコン画像">
<input type="text">
```

---

### 親子関係（入れ子）

タグの中に別のタグを入れることができます。これを「入れ子（ネスト）」と呼びます。
外側のタグを**親要素**、内側のタグを**子要素**と呼びます。

```html
<!-- div（親）の中に、h1とp（子）が入っている -->
<div id="card">
    <h1>タイトル</h1>
    <p>説明文です。</p>
</div>
```

---

## 3. 属性（Attribute）

タグには、名前や設定などの「属性」を追加できます。

### id（アイディー）: 世界に一つだけの名前
JavaScriptから特定の要素を操るために、**タグに名前（ID）** をつけます。
**ルール**: 1つのページの中に、同じIDは1回しか使えません。

```html
<button id="start-btn">スタート</button>
<div id="score-board">0</div>
```

---

### class（クラス）: グループ名

CSSで「まとめてデザイン」したい時に使います。IDとは違い、同じ名前を何度でも使えます。

```html
<p class="red-text">ここは赤くなる</p>
<p class="red-text">ここも赤くなる</p>
```

## 見た目を整えよう

---

## 4. CSS: 見た目の指定

HTMLで作った骨組みに、色や大きさなどの「見た目」を指定します。
今回は手軽な `style` 属性（インラインスタイル）を使います。

### 書き方
`style="プロパティ: 値;"`

```html
<!-- 文字の色（color）を赤（red）にする -->
<p style="color: red;">危険！</p>

<!-- 背景（background-color）を青、文字を白にする -->
<button style="background-color: blue; color: white;">青いボタン</button>
```

---

### よく使うプロパティ

| プロパティ | 意味 | 値の例 |
| :--- | :--- | :--- |
| `color` | 文字色 | `red`, `#333`, `rgb(255, 0, 0)` |
| `background-color` | 背景色 | `yellow`, `#f0f0f0` |
| `font-size` | 文字サイズ | `20px`, `1.5em` |
| `text-align` | 文字揃え | `center` (中央), `right` (右) |
| `border` | 枠線 | `1px solid black` (1pxの実線) |
| `padding` | 内側の余白 | `10px` |

## やってみよう！

次の完成図を目指して、HTMLを書いてみてください。

**【完成イメージ】**
- 箱（`div`）の中に、タイトル（`h2`）、説明（`p`）、ボタン（`button`）が入っている。
- 箱には枠線（border）と余白（padding）がついている。
- ボタンには `id` がついている（次以降のレベルで使います）。
- タイトルや文字の色を好きな色に変えてみる。

---

### テンプレート

```html
<div style="border: 2px solid #333; padding: 20px; text-align: center;">
    <h2 style="...">プロフィール</h2>
    <p>自己紹介をここに書く</p>
    <button id="greet-btn" style="...">挨拶する</button>
</div>
```
