# Mission A ★☆☆

# テーマを変えよう

---

## Mission A: 何をするか

Step 3 は「おにぎり屋さん」テーマだった。

これを **自分のテーマ** に書き換えよう。

変えるのは 3 箇所：

1. クリックする絵文字（`index.html`）
2. アイテムの名前（`script.js`）
3. 色（`style.css`）

`phases/missionA.md` を見ながら進めよう。

---

## Mission A: テーマの例

| テーマ         | クリック | アイテム例                  |
| -------------- | -------- | --------------------------- |
| カフェ         | ☕       | バリスタ、コーヒーメーカー… |
| 宇宙探検       | 🚀       | 衛星、宇宙ステーション…     |
| 魔法使い       | ✨       | 弟子、図書館、魔法陣…       |
| 自分のアイデア | 何でも！ | 自由に！                    |

**決まらなければ「カフェ」で進めてOK。**

# Mission B ★★☆

# アイテムを追加しよう

---

## Mission B: 何をするか

`script.js` の `items` 配列に **新しいアイテムを 1 つ追加** しよう。

```js
const items = [
	// ... 既存のアイテム ...
	// ↓ ここに追加するだけ！
	{
		id: "rocket",
		name: "???",
		price: 10000,
		power: 500,
		isAuto: true,
		count: 0,
	},
];
```

名前・値段・パワーは自分で決める。

`phases/missionB.md` にバランスの目安が書いてある。

# ミッション全部クリア？

# じゃあ、自由改造タイム

---

## 自由改造: 「もっとこうしたい」を形にしよう

ミッションをやって「ここ変えたい」「これ追加したい」と思ったことはある？

**そのアイデアをそのまま実装してみよう。**

---

## 自由改造のヒント

何も浮かばなければ、ミッションを深堀りしてみよう。

| ミッションの続き | 内容                                     |
| ---------------- | ---------------------------------------- |
| A の続き         | ショップのタイトルや背景画像も変える     |
| B の続き         | アイテムをもっと追加してゲームを長くする |
| C の続き         | オートセーブ・リセットボタンを追加する   |

**もっとやりたい人向けのアイデア：**

- 実績システム（○○円達成したらメッセージを表示）
- スマホ対応のレイアウトにする
- 全然違うゲームを作り直す

どんな小さな変更でも OK。
